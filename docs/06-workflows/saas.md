# 22. SaaS Company Workflow

> **Tier:** Pro + Agency | **Part:** Company Workflow Simulations

## Mid-Size SaaS Documentation Structure

A mid-size SaaS company (like NotiFlow post Series A) has:
- Dedicated documentation team (2–5 writers)
- Formal review process
- Documentation standards and style guide
- Multiple products to document

## Documentation Team Roles

| Role | Responsibility |
|---|---|
| Lead Technical Writer | Standards, review, complex docs |
| Technical Writer | Endpoint docs, guides, tutorials |
| Developer Advocate | Code examples, tutorials, community |
| Editor | Quality review, consistency |

## Review Process

```
Writer drafts → Self-review → Engineer accuracy review →
Editor style review → PM sign-off → Publish
```

## NotiFlow Series A Simulation

**Team:** 1 lead writer, 2 writers, 1 developer advocate
**Process:** 3-stage review (engineer, editor, PM)
**Cadence:** Docs ship with every product release
**Standards:** 7Forge style guide enforced across all content

## Checklist

- [ ] Documentation team structure defined
- [ ] Review process documented
- [ ] Style guide enforced
- [ ] Documentation included in release process
