# 20. Freelancer Workflow

> **Tier:** All Tiers | **Part:** Company Workflow Simulations

## The Complete Freelance Project Lifecycle

```
Brief → Scope → Research → Plan → Write → Review → Deliver → Invoice
```

## Project Timeline (Typical 3-Week Project)

| Week | Activities |
|---|---|
| Week 1 | Intake, scoping, research, planning |
| Week 2 | Writing all documentation |
| Week 3 | Review, revisions, final delivery |

## Client Communication Templates

### Initial Response Email
```
Subject: Re: API Documentation Project

Hi [Name],

Thanks for reaching out. I specialize in API documentation
and would love to learn more about your project.

Could you share:
1. The API spec (OpenAPI YAML if you have one)
2. What documentation currently exists
3. Your timeline and budget

I'll review and come back with a scope and quote within 48 hours.

Best,
[Your name]
```

### Delivery Email
```
Subject: [Project Name] — Documentation Delivered

Hi [Name],

Your API documentation is complete and ready.

Live URL: [url]
GitHub repo: [repo link]

Included:
- API reference for all [X] endpoints
- Getting started guide
- Authentication guide
- Error code reference

Please review within [X] business days.
I've included [X] rounds of revisions in scope.

Best,
[Your name]
```

## NotiFlow Freelancer Simulation

**Client:** NotiFlow startup
**Project:** Document 12 endpoints + guides
**Timeline:** 3 weeks
**Price:** $2,400

Week 1: Scoped project, tested all endpoints in Postman, interviewed engineer, found 4 gaps
Week 2: Wrote all 15 documentation pages using 7Forge templates
Week 3: Engineer review (4 corrections), final revisions, delivered via GitHub + live URL
