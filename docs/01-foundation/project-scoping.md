# 3. Project Scoping & Requirements

> **Tier:** Pro + Agency | **Part:** Foundation

## Scope of Work Template

```markdown
## Scope of Work — [Client Name]

**Project:** [Name]
**Date:** [Date]
**Writer:** [Your name]

### Deliverables
1. API Reference for [X] endpoints
2. Getting Started Guide
3. Authentication Guide
4. Error Code Reference

### Out of Scope
- SDK documentation
- Video tutorials

### Timeline
| Milestone | Due Date |
|---|---|
| Research complete | [Date] |
| First draft | [Date] |
| Final delivery | [Date] |

### Revisions
Includes [X] rounds. Additional revisions at $[rate]/hour.

### Price
Total: $[amount]
```

## NotiFlow Example

**Audit:** 12 endpoints, 4 documented, 8 missing, no getting started guide
**Scope:** All 12 endpoints + getting started + auth guide + error reference
**Timeline:** 3 weeks | **Price:** $2,400

## Checklist

- [ ] Documentation audit complete
- [ ] Scope of work created and signed
- [ ] Engineering contact confirmed
- [ ] API access confirmed
- [ ] Timeline and payment agreed
